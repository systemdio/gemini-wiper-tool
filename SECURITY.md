# Security Policy

## Reporting a Vulnerability

Email **hjcs@tuta.io** with details. Use GitHub Security Advisories for private disclosure. Do not create a public issue for sensitive findings.

Response target: 48h acknowledgement, fix within 7 days for critical issues.

## Scope

Gemini Wiper runs entirely in the browser. No backend, no telemetry, no data collection. All operations are DOM automation on `https://gemini.google.com`.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
